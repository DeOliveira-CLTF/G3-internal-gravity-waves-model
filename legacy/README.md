# Legacy material

This directory preserves the repository state that preceded the manuscript-
oriented reorganization. It is retained only for provenance and regression
comparison; none of these files is imported or executed by the active workflow.

- `original_portuguese_sources/` contains frozen historical scripts. Their
  original language and formulas are intentionally unchanged so that the
  reorganization remains auditable.
- `working_drafts/` contains previously untracked exploratory scripts, including
  two empty placeholders. The maintained implementations are under
  `experiments/`.
- `original_outputs/` contains figures and tables generated by the historical
  scripts.

International reviewers should use the English modules and outputs documented
in the repository root `README.md`.
